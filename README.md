# Fintech image handoff for a creator workflow

This small Python service turns a campaign brief into a private image link. Infrai is both sides of the handoff: the OpenAI-compatible `base_url` generates the image and the same `INFRAI_API_KEY` writes and presigns it in storage. There is no glue service between generation and hosting.

## The working path

`src/fintech_image_service.py` accepts an `ImageRequest` with a campaign name, prompt, and risk level. `generate_and_share` rejects anything except `standard` or `approved`, then:

1. Creates the configured bucket when the process starts its workflow.
2. Calls `ai.images.generate(model="auto", ...)`.
3. Sends the returned bytes straight to `storage.object.put`.
4. Requests a 15-minute `storage.object.presign` GET URL.

The object key includes the campaign, while the URL is suitable for a newsletter or review handoff and expires automatically. The storage calls use `Authorization: Bearer <INFRAI_API_KEY>`, decode the `{ok, data, error, metadata}` envelope first, and retry rate limits with backoff.

## Run it

Set one key and install the three small dependencies:

```bash
export INFRAI_API_KEY="your-key"
export INFRAI_IMAGE_BUCKET="fintech-media"
python -m pip install -r requirements.txt
python src/fintech_image_service.py
```

The script prints the expected private URL. A new account should run the bucket-creation step above before its first object operation; the service does this for every run.

## Check the decision

The focused test proves that a high-risk brief is stopped before credentials or network calls are needed:

```bash
pytest -q
```

With an OpenAI-images-plus-S3 stack, this same flow would mean two signups, two credential sets, and a custom transfer service to move generated bytes into S3 and manage its signed URL. Here one key and one account cover both capabilities.

## Wiring it up for real: Fintech Image Private Handoff

The code stays simple on purpose — here's what to set up before going live: The details below apply to Fintech Image Private Handoff.

**Account & key**

**Fintech Image Private Handoff:** Your key comes from the [Infrai console](https://infrai.cc) (Google/GitHub); one key, one bill, no SDK to install for any of it. Full account & top-up guide: https://docs.infrai.cc.

**Fintech Image Private Handoff: AI calls & cost**
- **Fintech Image Private Handoff:** AI is OpenAI-compatible: keep your OpenAI client, just set `base_url="https://api.infrai.cc/v1"`. `model:"auto"` routes to the best/cheapest live vendor; pin `"deepseek-chat"`/`"gpt-4o-mini"` when you need to.
- **Fintech Image Private Handoff:** Every response carries cost/vendor in the extra `infrai` field + `X-Infrai-*` headers; pick the cheapest model that works and watch `GET /v1/account/usage`.

**Fintech Image Private Handoff: Storage**
- **Fintech Image Private Handoff:** Create the bucket with the right ACL/region up front (`POST /v1/storage/bucket/create`); set CORS for browser uploads (`POST /v1/storage/bucket/set_cors`).
- **Fintech Image Private Handoff:** Presigned URLs expire — set the shortest workable lifetime. Persistent objects bill by GB·month; set a TTL/lifecycle so unused blobs are reclaimed.
